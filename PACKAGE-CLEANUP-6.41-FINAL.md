# DOU Assess 6.41 — Final Package Hygiene

Final distribution rules:

- No runtime `dou_assess.db` or other SQLite database.
- No `.pytest_cache`, `__pycache__`, `.pyc` or `.pyo` files.
- `data/evidence`, `data/scans`, and `data/ops` contain no test/runtime artifacts.
- Official-template uploads generated by tests are not shipped as if they were institution-approved official sources.
- `.env.example`, `.env.production.example` and pilot-development example configuration may ship; real secrets never ship.
- `PACKAGE-MANIFEST-SHA256.txt` is regenerated after all cleanup and documentation updates.
- The final ZIP is extracted to a new directory and manifest/test validation is repeated from extracted content.
