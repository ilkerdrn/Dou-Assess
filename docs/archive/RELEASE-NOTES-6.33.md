# DOU Assess 6.33 — Evidence Readiness & Accreditation Visit Mode

Sürüm: `6.33-evidence-readiness-visit-mode-server-ready`

## Yeni
- Program + akademik yıl + aktif kalite framework'ü için kriter→kanıt→PUKÖ hazırlık matrisi.
- Her kriterde doğrudan kanıt sayısı, açık/kapalı PUKÖ, eksik kalite sinyalleri ve açıklanabilir ziyaret hazırlık skoru.
- Öncelikli eksik kanıt/kriter listesi.
- MEDEK / MÜDEK / TURAK / YÖKAK / ESG / ACQUIN ile aynı framework motoru üzerinde çalışır.
- Ziyaret/denetim sırasında operasyonel karmaşayı gizleyen odaklı read-only görsel mod.
- Hazırlık göstergesi resmî akreditasyon puanı değildir; kurum içi hazırlık ve eksik kanıt yönetimi içindir.

## Korunanlar
6.32 kapalı kalite döngüsü, 6.31 kalite takvimi, 6.30 eskalasyon, 6.29 aksiyon motoru, 6.28 yönetim kalite merkezi ve 6.27 framework routing korunur.
