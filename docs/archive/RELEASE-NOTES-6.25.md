# DOU Assess 6.25 — Academic Intelligence

Sürüm: `6.25-academic-intelligence-server-ready`
Şema: `0020_assessment_intelligence` — yeni migration yoktur.

## Öğretim elemanı UX
- Varsayılan açılış: **Derslerim**.
- Ders kartından yalnız dört işlem: Sınavlar, Soru Bankası, Öğrenciler, Ders Analizi.
- Öğrenci işlemi ana CRUD ekranına değil seçili dersin salt-okunur öğrenci listesine gider.
- Program/Ders/Öğrenci ana veri kurulum menüsü normal öğretim elemanından gizlenir.

## Ders Analizi
- Sınıf ortalaması, geçme oranı, ÖÇ hedef karşılama, resmî sınav ve riskli soru KPI'ları.
- ÖÇ başarı/hedef karşılaştırması.
- Aynı program + aynı ders kodu için dönemler arası trend.
- Dönem trendinden sınav analizine drill-down.

## Program Analizi
- Ölçüm kapsamı, PÇ ortalaması, açık PUKÖ ve kritik ders KPI'ları.
- PÇ hedef karşılama görünümü.
- Dönemler arası program trendi.
- Riskli/ölçülmeyen dersten Ders Analizi'ne drill-down.

## Korunan motorlar
Soru bankası, belirtke, sınav yaşam döngüsü, OMR, klasik puanlama, psikometri, ÖÇ/PÇ, Quality360, kanıt ve akreditasyon motorları korunur.
