# DOU Assess 6.18 — OBS / Akademik Veri Köprüsü

İki giriş kanalı vardır:

1. OBS'den alınan kurumsal Excel/senkron adaptörü.
2. Öğretim elemanının kullanabileceği birleşik **Akademik Veri Excel Şablonu**.

Yeni şablon program, ders, öğrenci, ders kaydı, ÖÇ/PÇ, sınav ve soruları destekler. Öğretim elemanı yalnız yetkili mevcut derslerini doldurabilir; admin program/ders yapısını da oluşturabilir.

Gerçek OBS API bilgileri Bilgi İşlem tarafından sağlandığında aynı harici kimlik/senkron katmanına bağlanmalıdır. Doğrudan OBS API bağlantısı gerçek sözleşme alınmadan test edilmiş sayılmaz.
