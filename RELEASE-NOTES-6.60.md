# DOU Assess 6.60 — Generic Assessment Measure + Rubric Engine

- Adds a generic assessment layer independent from exam-only workflows.
- Supports exam, assignment, project, presentation, laboratory, internship, portfolio, capstone, practical and peer assessment measures.
- Adds reusable, versioned rubric templates with criteria, performance levels and optional Learning Outcome links.
- Adds measure-to-Learning Outcome mappings and student measure results.
- Rubric-scored results are server validated and raw score is derived from criterion scores.
- Adds measure summary analytics: result count, average, target achievement and outcome-analysis readiness.
- Adds an instructor/management workspace for Measure Plan & Rubrics.
- Existing exam/OMR/classic grading paths remain unchanged and compatible.
